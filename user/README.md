# user/ —— 本技能用户的听课产出（本地产出，不入版本库）

每场「持续听课」的完整产出自动落盘到本目录，一场一个目录：

```
user/session/<主播账号>_<直播主题>_<开始时间>/   ← B站等能抓到公开数据时
user/session/<开始时间>/                        ← 抖音/小红书/视频号等抓不到时降级纯时间
    ├── meta.json            # 场次元信息（来源链接/标题/主播名/听课人/开始时间/段长）
    ├── chunks/seg_*.wav     # 音频分块（近流式默认 5s 一段）
    ├── transcripts/
    │   ├── segments.jsonl  # 逐段结构化转写（实时追加）
    │   └── transcript.txt  # 纯文字稿（实时追加，最终交付物）
    ├── record.log / transcribe.log / listen.log
```

- 目录名命名规则（降级链）：
  - **能抓**到主播/主题（B站等有公开接口）→ `主播账号_直播主题_开始时间`，如 `天津极品相声帮_华为MateXT2发布会_20260907-1738`；
  - **抓不到**（抖音/小红书/视频号等无公开接口、且禁用浏览器自动化）→ 目录直接用**纯本地时间** `20260907-1738`，不报错照常内录。
- 抓取只需**公开接口 + 直接请求**，不碰浏览器自动化。
- `--user <听课人标识>` **只记入 `meta.json`**，不参与目录名。
- `transcript.txt` 是**边听边流式追加**的最终文字稿，可直接打开阅读。
- 本目录内容是**本机/本使用者的听课记录**，体积可能很大（音频+持续增长的稿子），
  因此在 `.gitignore` 中排除、**不进入 git**；它只是仓库工作树里的本地落盘位置。

## 由谁生成

推荐用统一编排命令（一条命令自动听完一整场并实时出字）：

```bash
# 给任意直播链接即可（B站自动抓主播/主题；抖音/小红书等自动降级纯时间目录）
python scripts/listen.py --url <任意直播URL> --user <你的标识>

# B站数字简写也可以：
python scripts/listen.py --room <B站房间号> --user <你的标识>

# 没人值守跑一整场（B站未开播会等、结束自动收尾），放后台：
nohup python scripts/listen.py --url https://live.bilibili.com/1816490612 \
      --user me --wait-start > user/listen_me.log 2>&1 &
```

`listen.py` 会自动：认链接 → (B站等能抓时)抓主播/主题建带名目录 / (抓不到时)降级纯时间目录 →
内录(5s 近流式小分块) → 秒级增量转写出字 → 检测到下播自动停录收尾 → 产出最终 `transcript.txt`。
- **B站等有接口平台**：自动判开播/下播，可无人值守。
- **抖音/小红书/视频号等盲录平台**：无状态接口判下播，改用**「连续静音自动收尾」**——主播下播/关页后
  系统不再出声，内录不再落分块，连续 `--silent-timeout` 分钟（默认 3）无声音即自动收尾；
  可再叠加 `--max-minutes` 定时兜底，或到时 Ctrl-C。
  录制期间请自行打开直播页出声。
转写默认 **GPU 优先、无 GPU 自动降 CPU**，单块失败自动跳过，可稳定跑 60 分钟以上。
